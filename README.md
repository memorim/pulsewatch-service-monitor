# Pulsewatch — панель состояния сервисов

Демонстрирует интерфейс статусов, метрик и инцидентов.

**Тип:** Самостоятельный портфолио-проект. Рабочая демонстрационная реализация; коммерческий запуск и использование реальными пользователями не заявляются.

## Что работает
- Показ сохранённых мониторов и журнала инцидентов.
- Создание монитора в интерфейсе.
- API ручного обновления статуса и создания/закрытия инцидента.

## Стек
JavaScript, Express, SQLite, Zod, HTML, CSS.

## Запуск и проверка
Node.js 24 и pnpm 11.

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm start
```

## Технические решения
- Общий статус рассчитывается по сохранённым статусам мониторов.
- Запись метрик и показ интерфейса отделены от отсутствующего механизма сетевой проверки.

## Границы готовности
- Сервис сам не опрашивает сайты и API: фонового сборщика метрик нет.
- Uptime, графики и подписи времени в макете не являются результатом наблюдений за реальными сервисами.
- Не реализованы уведомления, команда, авторизация и SLA.
