# Pulsewatch — панель состояния сервисов

Проверяет HTTP-доступность сервисов и сохраняет историю задержек, сбоев и восстановления.

**Проект:** Самостоятельная разработка.

## Что работает
- Фоновые HTTPS-проверки по расписанию и ручной запуск цикла.
- Время ответа, доля успешных проверок и график из сохранённой истории.
- Инцидент после двух ошибок подряд и автоматическое закрытие при восстановлении.
- Проверка домена, DNS/IP и каждого перенаправления; ограничение времени и хранения истории.

## Стек
JavaScript, Express, SQLite, Zod, HTML, CSS.

## Запуск и проверка
Node.js 24.18.0 и pnpm 11.7.0.

```bash
npm install --global pnpm@11.7.0
pnpm install --frozen-lockfile
pnpm test
pnpm start
```

## Технические решения
- IP закрепляется на время запроса: DNS-проверка и сетевое соединение используют один адрес.
- Метрики вычисляются по наблюдениям; до первого результата интерфейс показывает ожидание.
- Изменение схемы и запись результатов выполняются транзакционно.

## Проверка интерфейса

Playwright проверяет компьютерную и мобильную версии, отсутствие горизонтального прокручивания и повтор загрузки после ответа API 503. Ошибка отправки формы сохраняет введённые данные.

```bash
pnpm exec playwright install chromium
pnpm test:e2e
```
